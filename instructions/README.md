# Site Instructions

Put the instructions for building the techstore-win site here, one Markdown file per topic. For example:

- `01-overview.md`: purpose, audience, overall look and feel
- `02-pages.md`: pages and sections (home, product listing, product detail, cart, etc.)
- `03-design.md`: colors, fonts, branding, reference sites
- `04-features.md`: features and behavior (search, filters, cart, checkout)
- `05-tech.md`: preferred stack and hosting, if any

Files are read in filename order. Nothing gets built until the instructions are confirmed.
